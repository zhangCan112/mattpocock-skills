# skill-trail

skill 激活足迹的采集与盘点上下文:记录会话里每一次 skill 激活(谁触发、何时、被什么请求引发),回答「用过什么、何时、为什么」。账目分两层:明细层供情境回看,累计层供终身判定。

## Language

**足迹明细层**:
按会话滚动的 skill 激活记录,设上限防膨胀,供情境回看。
_Avoid_: 历史、日志

**累计层**:
跨会话的终身计数,永不清算,供「从未触发/使用率」判定。
_Avoid_: 总账、统计表

**TrailStore**:
足迹双层的持有者:收新记录,保明细层与累计层的存储一致。
_Avoid_: 管理器、缓存

**水合**:
内存未跟踪的会话先增量落盘、再取回历史合并,防差分重复计数。
_Avoid_: 恢复、加载

**落账**:
已 durable 的累计增量经读-改-写并入存储,成功才出队。
_Avoid_: 保存、同步

**对账**:
回合结束时以 transcript × 事件账核对明细,补 @mention 盲区;幂等。
_Avoid_: 校对、比对

**扫频**:
对账的执行动作,带同会话限流与在飞去重。
_Avoid_: 轮询、扫描

**触发情境**:
激活前最近一条用户消息的摘录,回填进记录。
_Avoid_: 上下文提示
